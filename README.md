# The Fanny Chef

Sitio informativo de **The Fanny Chef** — chef privada en Guadalajara.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notas

- Assets en `public/img` (también hay copia en `img/`).
- Contenido editable en `src/data/content.ts`.
- CTA principal: WhatsApp con mensaje precargado.
